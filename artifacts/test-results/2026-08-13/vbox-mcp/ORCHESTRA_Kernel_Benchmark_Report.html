1. Executive summary

Yes — the kernel ORCHESTRA path was exercised: BPF object built against guest BTF, attached via bpftool struct_ops register, /sys/kernel/sched_ext/state=enabled, then compared to CFS and scx_simple under fixed-duration CPU and mixed workloads.

  • Userspace gates (Phase A/B): unit + integration PASS; signal microbenchmark 12/12 PASS; paper_cpu harness FAIL on metrics schema v6 vs v2/v5 manifests (runtime still produced CSVs).
  • Kernel attach (Phase C): sanity PASS; load / unload / reload PASS.
  • Benchmarks (Phase D/E): wall times for ~30s spins are nearly identical across schedulers (expected for fixed-duration busy loops). Context-switch activity is higher under ORCHESTRA than CFS/scx_simple.
  • Stability: Stage 8 held enabled for 1802 seconds with memory ~383–393 MB and no observed panics in the collected log.
Interpretation caution: Wall-clock on fixed-duration while sleep/busy loops is not a throughput claim. Prefer context-switch / telemetry deltas and conventional metrics on representative workloads for performance conclusions. All figures are VirtualBox-only.

2. Method & environment

Transport

Intended control plane was vagrant-mcp. Vagrant 2.3.7 rejects VirtualBox 7.2, so guest execution used SSH (vagrant@127.0.0.1:2222) and snapshots via VBoxManage (pre-full-test, pre-bpf-load, pre-stage8, post-full-test).

Kernel object under test

  • Scheduler BPF: kernel/sched_ext/orchestra_scx_stage7.bpf.o
  • Bridge CLI: kernel/sched_ext/bridge/orchestra_bridge
  • Kernel headers source: $HOME/src/linux-v6.12.96
  • Baselines: stock CFS; Fedora scx_simple

Workload model

Primary compare harnesses use pinned busy-wait workers for a fixed wall interval (~30s). Elapsed ≈ duration for all schedulers; differences appear mainly in scheduling counters.

7. Limitations & script defects

  • Platform: VirtualBox only — not bare-metal; virtualization noise affects absolute counters.
  • Workload: Fixed-duration busy loops do not establish throughput or latency superiority.
  • Ctxt metric: Scripts read cumulative /proc/stat ctxt; increments are approximate session deltas.
  • Stock benchmark_suite.sh: wait $(jobs -p) hangs on background scx_simple — fixed harness used for reported numbers.
  • Stock stress_suite.sh: memory fallback can write multi-GB /tmp files.
  • stage8_validate.sh: set -e aborts when invalid-PID publish returns non-zero.
  • Userspace paper_cpu harness: metrics schema mismatch (binary v6 vs manifest v2/v5).
